## 3. 設計判断の経緯（重要）

1. **初版**：元図のまま施工図化。水抜穴・面木・目地を追加。
   → 北面の根入れが約220～240mm（隣地-1660～-1680 vs 底盤下-1900）で、宅地防災マニュアル目安（35cm以上かつ0.15H）を下回ることを指摘。
2. **改1**：底盤を150下げ（下端-2050）。→ **櫨本様が却下**
   - 理由①：全高2,250となり、工作物確認申請（2m）の観点で不可との判断
   - 理由②：構造計算済みのため躯体寸法の変更は不可
   - 補足：施行令138条の擁壁高さは一般に「見え高さ」で判定（改1でも見え高さ約1.88m）と説明したが、方針として躯体不変を優先
3. **改2（採用）**：躯体は構造計算どおりに戻し、根入れは躯体外で確保
   - 北面全長＋西面NW隅から1.5m：**前面地盤を±0-1500に嵩上げ**（盛土転圧、外面から1.0m以上平坦→既存地盤へすり付け）
   - **前面ふかしコン W300（無筋 Fc18）**：底盤下端-1900～-1500、擁壁と一体打設可
   - 根入れ **400mm** 確保、北面見え高さ **約1,700mm**
   - 隣地は他人の土地ではない（櫨本様確認済み）／「コンクリートだけふかすスタイルならOK」との指示に基づく
   - 東面（道路側）・西面南側は既存地盤で根入れ充足のため対象外

5. **改3-1（2026/11/11）電線下 無改良区間の底盤補強**
   - 入力：`input/コラム伏図_柱状改良.pdf`（深層混合処理 φ500、L=2.10～3.85m×220本、Fc=900kN/m²、TL-3E）
   - 櫨本様の指示：電柱リスクはなくなったが、電線の下は改良機が入れず杭（改良体）が打てない → 鉄筋等で補強して基礎の連続性を持たせる
   - 打設不可範囲（櫨本様が「西面のみ」を選択）：**西面 NW隅から 700～5,000 の底盤全幅**（電線の平面位置から左右2.0m＝推定）。北面ヒールの内側は打設可能とみなす
   - 補強方針：無改良区間の地盤反力を無視し、①立上り＋底盤のL形断面 ②ヒール端の補強梁（上がり梁 500×1000、底盤共、天端-900）で両側の改良区間へ架け渡す（長期・許容応力度、単純支持で安全側）
   - 補強区間：NW隅～6,500（無改良区間の両側へ1.5m以上）。区間内は継手禁止・誘発目地なし → **西面のCJを 3,300/6,600 → 6,900 の1か所に変更**
   - 追加配筋：R1 天端 2-D19（SD345）、R2 底盤下端壁際 3-D19、R3 補強梁主筋 上下各3-D19、R4 あばら筋 D13@200、F1a・F2a 底盤主筋追加 D13@300（既存と交互で@150）。R1・R2・R3 の北端は北面へ折曲げ定着 40d=760
   - 検討結果（S-07④）：L形断面 M=198kN·m（許容301）、補強梁 M=90kN·m（許容142）、ヒール版 M=40.7kN·m/m（許容56.7）、せん断 τ≦0.38（許容0.70）→ すべてOK
   - 支点反力 約280kN（南端・隅角側）→ **改良体の再計算・増し打ちを改良業者に依頼**（S-07に増し打ち検討位置を表示）

## 6. 再生成手順（`src/`）

```bash
pip install -r src/requirements.txt          # numpy, matplotlib, ezdxf
python3 src/youheki.py out/youheki.pdf       # PDF＋各図PNG（out/youheki_S-0x.png）
python3 src/export_dxf.py out/dxf            # JW用DXF 7枚
```
- 日本語フォント：`/usr/share/fonts/opentype/ipafont-gothic/ipag.ttf`（IPAゴシック）を使用。無い環境では `youheki.py` 冒頭の `FONT` を変更
- 主な変更箇所（`youheki.py`）
  - レベル・断面：`H_TOP, GL, WJ, F_TOP, F_BOT`
  - 前面嵩上げ・ふかしコン：`FRONT`(-1500)、`FK_W`(1.5m)、`FK_T`(300)
  - 目地位置：`EJ_N`, `CJ_N`, `CJ_W`, `CJ_E`
  - 外部地盤：`ext_ground0()`（既存）、`ext_ground()`（嵩上げ後）
  - 水抜穴ルール：`weep_level()`, `holes_in_bay()`
  - 表題欄の改訂表記：`Sheet.frame()` の備考欄
  - 改3 電柱回避：`SHIFT_W`（西面の移動量 3.0m）、`POLE_DW`/`POLE_DN`（電柱の西・北境界からの離れ）、`POLE_R`、`WIRE_DIR`（上空線の方向）
    → 電柱を実測したらこの2つの値を直して再生成すれば、S-01・S-04・S-06の電柱位置と離れ寸法が追従する
  - 改3-1 無改良区間：`GAP_T0`/`GAP_T1`（打設不可範囲）、`GAP_EXT`、`EB_B`/`EB_D`/`EB_T0`（補強梁）、検討は `gap_calc()`、作図は `sheet_gap()`
  - 建柱車・掘削の検討条件：`EXC_WORK`/`EXC_SLOPE`/`EXC_DEPTH`、`TRUCK_W`/`TRUCK_L`/`TRUCK_OR`（`sheet_pole()`）
- DXFは `export_dxf.py` が `youheki.py` の描画命令をそのまま記録して出力する（PDFを直せばDXFも追従）
